# Publication checklist

This repository should remain private until every item below has been reviewed.

## Data and permissions

- [ ] No Bloomberg-derived input observations are committed anywhere in Git history
- [ ] No other licensed or course-restricted data are included
- [ ] Public-data sources and licences are documented
- [ ] Derived tables and figures are permitted for public display

## Privacy and attribution

- [ ] No phone numbers, private email addresses or student IDs appear in files or metadata
- [ ] The author and academic context are stated accurately
- [ ] Supervisor, university and third-party acknowledgements are added if required

## Reproducibility

- [ ] A clean environment can install `requirements.txt`
- [ ] The analysis runs from start to finish with authorised inputs
- [ ] Random seeds reproduce stochastic procedures
- [ ] Output tables and figures match the final thesis
- [ ] File paths are relative and contain no personal directories

## Claims and presentation

- [ ] README metrics match the source tables
- [ ] Negative and statistically insignificant findings are described accurately
- [ ] Benchmark definitions are clear
- [ ] Turnover, transaction-cost and implementation limitations are visible
- [ ] No language implies investment advice or production readiness

## GitHub presentation

- [ ] Repository description and topics are complete
- [ ] README renders correctly on GitHub
- [ ] Figures are legible on desktop and mobile
- [ ] Repository visibility is changed only after a final history review
